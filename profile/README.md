# WildNIX

WildNIX is a free (as in freedom) operating system built from the ground up.
We believe software should be open, auditable, and owned by its users, not corporations.

## Philosophy

- **Freedom first.** Every component of WildNIX is free software. No proprietary blobs, no hidden drivers, no exceptions.
- **Transparency.** The entire system from bootloader to userspace is open to inspection, modification, and redistribution.
- **Simplicity.** We favor small, composable tools over monolithic complexity.

## Status

Wildnix is in early development. Expect rough edges.

Current milestones:
- [ ] Bootloader
- [ ] RootFS image
- [ ] Kernel
- [ ] Init system
- [ ] Basic userspace (shell, coreutils)
- [ ] Package manager
- [ ] Self-hosting toolchain
